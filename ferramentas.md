# HTML : Quais elementos estão sendo usados?
h1 para criar um titulo,p para criar os paragrafos,br para dar espaçamento,li para criar as linhas na nav bar.
# CSS : Quais propriedades estão sendo usadas?
Color para colorir a as letras, background-color para colorir o fundo,font-family para personalizar a letra, border-box para fazer a borda do navbar,position: relative para centralizar o navbar.
